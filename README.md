# foto-org

This repository hosts the privacy policy for **foto-org**, a Windows photo
scanner, de-duplicator and organiser available on the Microsoft Store.

- **Microsoft Store:** https://apps.microsoft.com/detail/9NH9DM8K04CM
- **Privacy policy:** https://leocadle.github.io/foto-org-public/privacy.html

The foto-org application source is maintained separately and is not public.

For support, please use the contact listed on the foto-org page in the
Microsoft Store, or open an issue in this repository.
